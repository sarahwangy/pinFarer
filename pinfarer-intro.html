The Problem
Issue #1
Every traveller knows this pain.
01
Scattered saves
Browser bookmarks, WeChat messages, Notes app. A hidden Tuscany village — gone in three months.
02
No context
Just a name. No "why I saved this." No source link. No "Visited" vs "Dreaming" signal.
03
Planning from scratch
You have 40 saved pins. Building an itinerary still takes hours on Google Maps.
→ Pinfarer solves all three.
How It Works
4-step flow
Pin. Explore. Plan. Go.
1
📍
Pin a place
Click the globe map or search. Set status: Visited, Watchlist, or Dream. Add your source (YouTube, 小红书, book, self-explored).
2
🤖
AI enriches it
Claude Sonnet generates a place introduction — population, language, currency, climate, food culture, visa, safety — in one click.
3
📊
See your world
Dashboard shows KPIs, status donut, source breakdown, and country ranking. Your travel life in one view.
4
✈️
AI builds itinerary
Select saved pins, set trip length and style. Claude reads your library and returns a day-by-day plan with a live map route.

Layer
Technology
What it does
Framework
Next.js 14
App Router + TypeScript. SSR for place pages.
Map
Mapbox GL
Globe projection. Click-to-fly. Route dashed lines.
AI
Claude Sonnet
Place intro + city data + day-by-day itinerary.
Database
Supabase
PostgreSQL + JSONB. Stores all pins + AI summaries.
Images
Pixabay API
Server-side image proxy. Hero photos per place.
Auth
NextAuth
Google OAuth. Demo mode — no account needed.
Styling
Tailwind + shadcn
Component library + utility CSS. Fast iteration.
Deploy
Vercel
Auto-deploy on git push. pinfarer.vercel.app
